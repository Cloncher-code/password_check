# Бизнес-идея v1.0

**Проект:** «Проверка сложности пароля» · **Заказчик:** продуктовая команда онлайн-сервиса · **Дата:** 26.10.2026

**Проблема.** Пользователи придумывают слабые пароли и не знают, что изменить.

**Что нужно.** Виджет для формы регистрации: оценка надёжности, рекомендации, генерация надёжного пароля; то же через API. Пароль нигде не сохраняется.

**Цели:** Ц-1 уровень надёжности; Ц-2 рекомендации; Ц-3 API; Ц-4 пароль не утекает; Ц-5 генерация.

**Решения по вопросам этапа 0:** продуктовая команда; пароль остаётся в поле; кнопка «Показать / Скрыть»; длина до 64; пороги 0–39 / 40–69 / 70–89 / 90–100; 20 распространённых паролей; пробелы запрещены; последовательности — латиница и цифры; генерация входит.

**Не входит:** хранение паролей и истории, авторизация, внешние базы утечек, мультиязычность, ограничение частоты запросов.

**Ограничения:** локальный запуск, Python + FastAPI, без БД. Подробно — БТ v1.0.
