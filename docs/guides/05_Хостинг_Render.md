# Инструкция 5. Облачный хостинг на Render

Для кого: Андрей (владелец репозитория). Время: 15 минут. Стоимость: 0 ₽, банковская карта не нужна.

Результат: приложение доступно всем по адресу вида `https://password-check.onrender.com` с HTTPS; каждый push в `main` автоматически обновляет сайт.

## Что важно знать заранее

| Особенность бесплатного тарифа | Что это значит для нас |
|---|---|
| Сервис «засыпает» после 15 минут без запросов | Первый запрос после паузы — около минуты ожидания. Перед показом преподавателю откройте сайт заранее |
| 750 бесплатных часов в месяц на аккаунт | Хватает на один сервис круглосуточно |
| Файлы на диске стираются при перезапуске | Нам не важно: приложение ничего не хранит |
| Логи доступны в панели Render | Пароли туда не попадают (НФТ-05, TC-19) |

Если сайт открывается впервые за день и долго грузится — это пробуждение, а не ошибка.

## Что уже подготовлено в проекте

| Файл | Зачем |
|---|---|
| `render.yaml` | описание сервиса: установка зависимостей, команда запуска, проверка `/health` |
| `.python-version` | версия Python 3.12. Без него Render возьмёт свою версию по умолчанию (новее 3.13), под которую закреплённые библиотеки могут не собраться |

Команда запуска на хостинге отличается от локальной двумя параметрами: `--host 0.0.0.0` (принимать запросы снаружи) и `--port $PORT` (порт назначает Render). Без `--reload`.

## Шаги

1. **Убедитесь, что `render.yaml` и `.python-version` уже на GitHub** (в корне репозитория). Если нет — «Фиксация и отправка» в VS Code.
2. Откройте https://render.com → **Get Started** → **GitHub**: вход через аккаунт GitHub, отдельная регистрация не нужна.
3. Render попросит доступ к репозиториям. Выберите **Only select repositories** → `password_check` → Install.
4. В панели Render: **New** → **Blueprint** → выберите `password_check` → Render прочитает `render.yaml` и покажет сервис `password-check` с планом Free.
5. Нажмите **Apply** (или **Deploy Blueprint**). Сборка займёт 2–4 минуты; прогресс — во вкладке **Logs**.
6. Признак успеха в логах: `Uvicorn running on http://0.0.0.0:...` и `Your service is live`. Адрес сайта — вверху страницы сервиса.
7. Проверьте:
   - `https://<адрес>/health` → `{"status":"ok"}`;
   - главная страница: `Qwerty789!` → «Надёжный», «Балл: 75 из 100»;
   - `https://<адрес>/docs` — документация API.

Если имя `password-check` занято, Render добавит к адресу суффикс — это нормально.

## Как обновлять

Ничего делать не нужно: каждый push в `main` запускает пересборку и выкладку. Если сборка упадёт, сайт останется на предыдущей рабочей версии, а в Render придёт уведомление на почту.

## Частые проблемы

| Симптом в логах Render | Причина | Что сделать |
|---|---|---|
| `Using Python version 3.13…` или `3.14…`, затем ошибка сборки `pydantic-core` | не подхватился `.python-version` | проверьте, что файл в корне и содержит `3.12`; в панели: Environment → добавить `PYTHON_VERSION` = `3.12.7` → Manual Deploy |
| `No open ports detected` | запуск без `--host 0.0.0.0 --port $PORT` | сверить Start Command с `render.yaml` |
| `ModuleNotFoundError` | зависимость не в `requirements.txt` | добавить в `requirements.txt`, push |
| Сайт открывается минуту | сервис просыпался | норма для бесплатного тарифа |

## Безопасность публичного сайта

- HTTPS Render включает сам; пароль идёт только в теле POST-запроса по зашифрованному соединению.
- Ограничения частоты запросов нет (вне рамок MVP, БТ §6) — сайт можно нагружать запросами. Для учебного стенда приемлемо.
- Это учебный проект: попросите проверяющих не вводить пароли, которыми они реально пользуются.
