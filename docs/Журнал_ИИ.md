## Где ИИ ошибся сам (для отчёта по заданию)

- Тесты безопасности сначала использовали пароли из Приложения А и ложно падали на слове «password» (BUG-01).
- В первой версии штрафа P2 символ Кельвина считался латинской буквой (BUG-02).
- Файл CI не проверен парсером YAML: двоеточие в названии шага сломало workflow, ошибку нашёл GitHub Actions при первом push (BUG-03).
- Скрипт запуска использовал `--reload` и не проверял версию Python: на Mac сервер бесконечно перезапускался, окружение создалось на 3.9 (BUG-04, BUG-05). Первая попытка исправления (`--reload-dir`) не помогла — выяснено тестом до отдачи пользователю.
- Архив с исправлениями собран без флага UTF-8: кириллические имена отображались кракозябрами в macOS `unzip` (BUG-06).
- Автопроверка UI через Playwright упёрлась в собственную CSP приложения; пришлось менять способ проверки, не ослабляя CSP.
