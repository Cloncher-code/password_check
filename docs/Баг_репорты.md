# Баг-репорты

| Поле | BUG-01 | BUG-02 |
|---|---|---|
| Заголовок | Тесты НФТ-05 ложно падают: тестовые пароли совпадают с обычными словами страницы и URL | Штраф P2 может срабатывать на не-латинских символах, которые `lower()` превращает в латиницу |
| Требование | НФТ-05 (TC-16, 17, 19) | БП-03 |
| Критичность | major (тесты не дают сигнала) | minor |
| Тип | дефект теста | дефект кода |
| Шаги | 1. Взять пароли из Приложения А. 2. Прогнать проверки. 3. Искать каждый пароль в логах и HTML | 1. В `_seq_value` использовать `ch.lower()` и сравнение с a–z. 2. Подать символ Кельвина K (U+212A) |
| Данные | «password» | `\u212Aab` |
| Ожидаемый результат | 0 вхождений паролей | P2 только для ASCII-латиницы |
| Фактический результат | «password» найден: он есть в `/api/v1/password/check` и `name="password"` | K.lower() = «k» → считался латиницей |
| Окружение | Linux, Python 3.12.3 | ревью кода до прогона |
| Исправление | пароли-канарейки — уникальные строки, которых нет в интерфейсе | проверка `ch.isascii() and ch.isalpha()` |
| Статус | исправлен → проверен | исправлен → проверен |
